Choose the kind

Every project is scoped with you before work begins. We provide a written proposal with deliverables, assumptions, timing, and a fixed quote for the agreed scope.

01 / PLAN

Product discovery

Turn an early idea into a practical plan for what to build next.

Custom quote after an initial conversation

A good fit if You have a problem or idea but need help deciding what to build first.

Possible deliverables

  • Goals, user needs, and problem statement
  • Prioritized first-release feature list
  • Core user journeys and rough wireframes
  • Recommended technical direction and risks
  • Written scope for the next phase

Not included by default: Production implementation, user research recruitment, or a complete visual design system.

02 / DESIGN

Design & prototype

Make the experience concrete and testable before committing to a build.

Custom quote based on screens and flows

A good fit if You need to communicate, validate, or refine the product experience before development.

Possible deliverables

  • Information architecture and key user flows
  • Wireframes for agreed screens
  • Responsive visual design direction
  • Clickable prototype for review
  • Developer handoff notes and assets

Not included by default: Production code, formal usability testing, or additional revision rounds beyond the proposal.

03 / BUILD

Website or app MVP

Build a focused first release around a defined user problem and agreed feature set.

Custom quote after scope and requirements review

A good fit if You are ready to turn an approved plan or design into a usable first release.

Possible deliverables

  • Agreed website, Android app, or web app features
  • Development environment and source code
  • Review builds and agreed testing
  • Launch checklist and deployment support
  • Documentation and project handoff

Not included by default: Hosting, paid third-party services, app-store fees, content creation, or features outside the agreed scope.

04 / SUPPORT

Ongoing care

Keep an existing website or application healthy and improve it in planned increments.

Monthly plan scope and fee agreed before start

A good fit if You need a steady technical partner after launch or for software you already own.

Possible deliverables

  • Maintenance and dependency review
  • Bug triage and agreed fixes
  • Small, prioritized improvements

NO SURPRISES

Know what you’re agreeing to.

Before work begins, the proposal should spell out deliverables, assumptions, review points, timeline, payment schedule, ownership and handoff, third-party costs, and how changes are handled. Work outside the agreed scope is discussed before it’s added.

Prices are custom because effort depends on features, integrations, content, and existing systems. No fee, timeline, or outcome is promised until confirmed in a written proposal.
