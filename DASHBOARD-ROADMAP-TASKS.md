# Website and Dashboard Upgrade Checklist

Check a box to select an item for implementation; a checked box means selected,
not completed. Progress is tracked in the implementation plan. You selected the
full roadmap to be implemented in phases. Items marked **Optional** remain
subject to the privacy, moderation, and product decisions in the plan.

## Phase 1 — Dashboard foundation

- [x] **DASH-01** — Reorganize the staff dashboard with clear navigation for overview, inquiries, resources, releases, themes, reports, and settings.
- [x] **PUB-01** — Add step-by-step publishing instructions for Android, WordPress themes, WordPress plugins, iOS, and web projects.
- [x] **DASH-02** — Add a dashboard overview with accurate counts for published resources, releases, open inquiries, and recent activity.
- [x] **DASH-03** — Add quick actions for publishing an app/build, publishing a theme, and reviewing inquiries.
- [x] **DASH-04** — Make the staff dashboard responsive and accessible on mobile, keyboard, and screen readers.
- [x] **DASH-05** — Add recent releases and draft-release counts; add pending-review summaries after a review state exists.

## Phase 2 — Resource and release management

- [x] **REL-01** — Add a staff app/resource manager with search, filters, and clear draft/published/retired states.
- [x] **REL-02** — Show each resource's release history, version, release date, changelog, build format, and file details.
- [x] **REL-03** — Distinguish stable, beta, and archived releases, if those channels are needed.
- [x] **REL-04** — Add safe edit, retire, hide/unpublish, and restore actions with confirmation and clear consequences.
- [x] **REL-05** — Add storage usage reporting and a safe cleanup workflow that never deletes a file still referenced by a release.
- [x] **REL-06** — Add a publishing preview and pre-publish validation checklist.

## Phase 3 — Resource metadata and discovery

- [x] **DISC-01** — Add categories and searchable tags for apps, AAB/APK builds, and themes.
- [x] **DISC-02** — Add app icons, screenshots, developer details, compatibility information, and support/privacy links.
- [x] **DISC-03** — Build public resource detail pages with versions, changelogs, requirements, setup instructions, and download actions.
- [x] **DISC-04** — Add public search, category/tag/platform filters, and sorting by newest or most downloaded.
- [x] **DISC-05** — Add featured, new-release, and theme sections to the public library and homepage.
- [x] **DISC-06** — Improve page titles, descriptions, and social-share previews for public resource pages.

## Phase 4 — Review, safety, and administration

- [x] **OPS-01** — Add a staff review queue for drafts and packages that need approval, rejection, or updates.
- [x] **OPS-02** — Record review notes and a release checklist covering ownership, licenses, secrets, private data, and installation/testing.
- [x] **OPS-03** — Add a staff activity log for publishing, editing, hiding, retiring, and cleanup actions.
- [x] **OPS-04** — Add role management only if more than one staff permission level is needed.
- [x] **OPS-05** — Add a public issue/report form for a resource and a staff workflow to resolve reports.
- [x] **OPS-06** — Add a clear notification area for failed uploads, review results, and important release events.

## Phase 5 — Analytics and optional engagement

- [x] **DATA-01** — Define privacy and retention rules for aggregate download analytics before collecting new event data.
- [x] **DATA-02** — Add daily/weekly download reports, popular resources, category trends, and storage trends.
- [x] **DATA-03** — Show useful download/activity history without exposing one user's activity to another.
- [x] **COMM-01** — Add resource ratings/reviews with abuse prevention and a moderation workflow. **Optional**
- [x] **COMM-02** — Add a resource comparison view. **Optional**
- [x] **COMM-03** — Add announcements, a newsletter, or customer stories. **Optional**
- [x] **COMM-04** — Add AI-assisted search, categorization, or workflow automation. **Optional; evaluate after the core catalog is used.**

## Phase 6 — Dashboard personalization

- [x] **UX-01** — Let staff reorder dashboard widgets and save the layout.
- [x] **UX-02** — Make widget reordering work with keyboard and touch as well as drag-and-drop.
- [x] **UX-03** — Let staff reorder featured resources from the publishing tools.

## Selection

All items are selected for phased implementation. Selection does not publish or
deploy anything automatically; each feature will be implemented and verified
before moving on. You can uncheck any item to remove it from scope.
